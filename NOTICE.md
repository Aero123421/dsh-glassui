# Notice

Glass UI (`dsh-glassui`) is an independently maintained, unofficial plugin for
DSH (DeepSeek Harness). It is not affiliated with or endorsed by DeepSeek.

"Liquid Glass" refers to the design language introduced by Apple Inc. and is
used only to describe the visual style this plugin imitates. This project is
not affiliated with or endorsed by Apple Inc., and it contains no Apple assets.

The plugin ships no DSH or DeepSeek logos or brand assets. The screenshots in
`docs/images/` show DSH Web with the plugin installed, for illustration only.
The built-in wallpapers are original artwork generated by
`src/shared/wallpapers.ts` and are released under this repository's MIT
license.
