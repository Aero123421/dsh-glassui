# Glass UI for DSH

**DSH（DeepSeek Harness）Web を Apple の Liquid Glass 風にするプラグインです。** サイドバー、入力欄、ダイアログ、メニュー、トーストを、好きな壁紙の上で透けてぼける・縁で屈折するガラスにします。DeepSeek・Apple とは関係のない非公式のプロジェクトです。

## 特長

- **DSH の見た目の約束ごとに沿う。** どの要素がサイドバーでどれがダイアログかを、クラス名ではなく DSH が塗りに使うデザイントークン（`--dsw-*`）から判断します。トークンや API の変更は互換性チェックと実際の DSH を使うテストで確認します。
- **邪魔をしない。** `<body>` 上のテーマ設定が優先されます。要素ごとの除外や、再読み込みなしのオフに対応します。
- **軽い。** 何も起きていない間は毎フレームの処理をしません。DOM の変化は時間を区切って少しずつ調べ、描画済みの Markdown は調べません。
- **アクセシビリティ。** 「透明度を下げる」「コントラストを上げる」「視差効果を減らす」と Windows のハイコントラストに従います。コードブロックは構文の色が読みやすい濃さのガラスになります（不透明のままにもできます）。
- **ブラウザが対応していれば本物の屈折。** Chromium 系ブラウザでは、入力欄・メニュー・トーストの縁が背景をレンズのように曲げます。それ以外のブラウザでも、屈折なしで同じガラスになります。
- **壁紙は 11 種類、うち 4 つは動く。** 波のような帯と、やわらかな色の広がりを、ライトとダークの両方で用意しています。「動く」壁紙はゆっくり流れ、ページの描き直しは毎秒 12 回だけで、「視差効果を減らす」では止まります。
- **壁紙はローカル・テレメトリなし。** 壁紙は小さなインライン SVG です。更新を確認・実行したときだけ、Hostが固定したGitHub配布元へ接続します。

## インストール

DSH `>=0.2.0-rc.2 <0.3.0-0` を対象とします。DSH はこの範囲の prerelease を含むため、0.2.1-alpha.3 とそれ以降の 0.2.x prerelease も対象で、0.3.0 の prerelease は対象外です。空の peer 範囲、`*` / `x` / `>=0`、下限か上限が無い範囲（`<0.3.0-0`、`<=0.2.9`、`<0.2.2`）、実行中の系列の外まで届く範囲（`>=0.0.0 <0.3.0-0`、0.2 系の `<99`、`^0`、`<0.3.0`）は互換性不明です。実画面を検証した版は 0.2.0-rc.2 と 0.2.1-rc.2（`next`）です。0.2.1-alpha.5（`alpha`）も token・API 契約を確認しています。

1. DSH Web の「Plugins → Add plugin」に `github:Aero123421/dsh-glassui#v0.2.5` を入力してインストールします。
2. ターミナルからなら:

   ```sh
   dsh plugin --profile web add github:Aero123421/dsh-glassui#v0.2.5
   ```

3. DSH に再起動を求められたら再起動し、DSH Web を開き直します。最初からガラスがオンになっていて、「設定 → Glass UI」で調整できます。

日本語の表示には dsh-japanese が必要です。このプラグインは英語・日本語・中国語の辞書を登録するだけで、言語 `ja` は追加しません。[dsh-japanese](https://github.com/Aero123421/dsh-japanese) を導入し、言語を日本語（ja-JP）にしてください。入っていないときは DSH の言語は中文と English だけで、Glass UI は英語のままです。zh-CN では、このプラグインに同梱した中国語の辞書を使います。

[リリースの tarball](https://github.com/Aero123421/dsh-glassui/releases/latest) の URL からもインストールできます。どちらもビルド済みのプラグインを含みます。

外すときは「Plugins」からアンインストールします（`dsh plugin --profile web remove dsh-glassui` でも外せます）。

## 設定

設定は DSH のプロファイルに保存されます。Plugins ページや設定ファイルからも変えられます。

| 項目                       | 既定           |                                                                                                                                                                                                                       |
| -------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ガラスの質感               | オン           | 全体のスイッチ。オフにするとすぐに DSH 本来の見た目に戻ります。                                                                                                                                                       |
| 透明度                     | 35             | 0 でいちばん透明、100 でほぼ不透明。                                                                                                                                                                                  |
| 壁紙                       | 自動           | Bay・Sunrise・Meadow・Graphite・Lagoon・Dusk・Dune、動く Tide・Aurora・Bloom・Prism、なし、カスタム。「自動」はブラウザでは Bay、macOS のデスクトップアプリでは壁紙なし（ウィンドウ越しにデスクトップが見えるため）。 |
| 画像の URL                 | —              | 壁紙を「カスタム」にしたときの画像。`http://` または `https://` の URL、DSH サーバー上のパス、base64 の画像 `data:` URL が使えます。                                                                                  |
| サイドバー                 | フローティング | 「フローティング」は角の丸い浮いたパネルに、「ドッキング」は DSH 本来の配置のままにします。                                                                                                                           |
| コードブロック             | ガラス         | 「ガラス」はコードが読みやすい濃さのガラスに、「不透明」は DSH 本来の不透明なコードブロックのままにします。                                                                                                           |
| インラインコードの不透明度 | 72             | 文章内のコード背景を独立して0〜100で調整します。プレビュー付き、推奨60〜85。コントラスト設定によって実際の不透明度が高くなる場合があります。                                                                          |
| 屈折                       | オン           | ガラスの縁で背景を曲げます（Chromium 系ブラウザ）。                                                                                                                                                                   |
| ポインターのハイライト     | オン           | マウスの位置にやわらかい光が当たります。タッチ画面と「視差効果を減らす」ではオフ。                                                                                                                                    |
| 変更しない要素             | —              | プラグインに触らせたくない要素の CSS セレクター（例: `.my-plugin-panel`）。                                                                                                                                           |

スライダーはドラッグ中に専用サンプルで即時プレビューし、離すと画面全体へ適用します。キーボードでの変更は即時に適用します。

設定画面の「互換性」には、見つけたガラスの数・見つからないトークン・処理時間をまとめた診断情報と、不具合報告用のコピーボタンもあります。

### 壁紙

![内蔵の壁紙（上がライト、下がダーク）](docs/images/wallpapers.png)

「動く」壁紙は、いくつかの大きな層を GPU の合成処理だけで動かしていて、再生中にメインスレッドの処理はありません。動きは毎秒 12 コマで進みます。ゆっくりした動きなので滑らかに見え、上にあるガラスの描き直しも画面のリフレッシュレートの 5 分の 1 で済みます。「視差効果を減らす」がオンなら最初の 1 コマで止まります。

## プラグインの更新

「設定 → Glass UI」に実行中の版と「プラグインの更新を確認」があります。確認と導入は別の操作です。導入前に設定の保存待ちを完了し、保存拒否や別画面からの設定変更があれば更新を止めます。

Host は固定した GitHub の安定版、DSH の対応範囲、取得サイズ、SHA-256、アーカイブの manifest を確認します。確認した tarball そのものを標準の plugin manager へ渡し、現在のプラグインを先に削除しません。設定と bundle の ON/OFF を維持します。GitHub・tarball のどちらから導入した場合も、以後の更新は profile の `.dsh-glassui-updates/` に置いた検証済みアーカイブへ固定します。profile が参照しているファイルは残してください。開発用パスや読取り専用 profile は手動更新を案内します。

応答が失われたときは操作 ID で結果を照合し、導入を再送しません。導入版と実行版を確認してから成功と表示し、必要なら Host の再起動を案内します。manager が置換を拒否しても現在の導入を残し、手動更新へ案内します。

**v0.2.3 以前から更新する場合:** DSH を停止し、上記の v0.2.5 の導入コマンドを実行してから DSH を起動し、Web を再読み込みしてください。旧版 updater の削除してから入れ直す経路を避けられます。旧版の復旧記録は、プラグインが導入されている間は読み取れます。旧更新ですでにプラグインがなくなった場合は、Plugins または CLI から導入してください。

## プラグインを作っている方へ

特に何もしなくて大丈夫です。対象の DSH トークンと影（elevation）を使うパネルを自動で検出します。細かく決めたいときは:

```html
<!-- この要素と中身には触らない -->
<div data-glassui-ignore>…</div>

<!-- 明示的にガラスにする: regular・dense・smoke -->
<div data-glassui-material="dense">…</div>
```

DSH のテーマ API（`ctx.theme.overrideTokens`）による上書きは `<body>` のインラインの値になるので、常にこのプラグインより優先されます。ガラスはそのとき有効な色から作るので、上書きした色がガラス越しにそのまま見えます。

## 対応ブラウザ

| ブラウザ                                                                             | ガラス | 屈折 |
| ------------------------------------------------------------------------------------ | ------ | ---- |
| Chrome・Edge・Brave・Arc・Opera（Chromium 111 以降、141・143・149・154・156 で検証） | ✓      | ✓    |
| DSH デスクトップアプリ                                                               | ✓      | ✓    |
| Safari 16.4 以降                                                                     | ✓      | —    |
| Firefox 115 以降                                                                     | ✓      | —    |

`backdrop-filter` がない環境では、文字が読めるよう、ほぼ不透明な塗りになります。

ガラスがオンのとき、入力欄のプレースホルダーと、入力欄の下のラベル（Workspace Write などの権限モードとモデル名）は、ガラスの上で 4.5:1 以上になる色をこのプラグインが指定します。ガラスをオフにすると DSH 本体の色に戻ります。DSH 0.2.1-rc.2 の画面では、戻ったライトのプレースホルダー（`#adb2b8`）は白の上で 2.13:1、ダークのキャプションは暗い入力欄の上で 3.76:1 です（同じキャプションの以前の読みは 3.61:1）。このプラグインは、ガラスをオフにしたときのその表示は変えません。

## しくみ

Host 側は DSH Web のページを描くたびに 3 行を足します。設定、静的なスタイルシート、最初の描画の前に `<html>` に目印を付ける短いスクリプトです。ブラウザ側は計算済みのスタイルを読んで面を見つけます。見張るトークンの色を 8 ビットで 1 段ずつずらして一意にし、背景がその色になっている要素を、そのトークンで塗られた面とみなします。見つけた要素に `data-glassui-*` 属性を付けると、`:root[data-glassui]` の下に閉じたスタイルシートが、その要素の上でトークンを `color-mix()` で半透明に置き換えてガラスにします。

屈折フィルターや優先順位の決まりは [docs/architecture.md](docs/architecture.md)、新しい DSH への対応の確かめ方は [docs/compatibility.md](docs/compatibility.md) にあります（英語）。
