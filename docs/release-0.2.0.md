# 0.2.0

Glass UI設定に、プラグイン本体の更新確認と導入操作を追加しました。ガラス効果をOFFにしても、英語・日本語・簡体字中国語で結果を確認できます。

- 更新前にスライダーなどの保存待ちと進行中の書き込みを完了します。保存拒否・別画面での設定変更があれば導入を止め、未保存のまま再起動を案内しません。
- 固定した正式ReleaseのSemVer、DSH対応範囲、checksum、archive内のpackage名・版・互換性を検証し、標準managerへ渡します。GitHub／tgzの導入経路とbundleのON/OFFを維持し、build scriptを自動承認しません。
- 同一ブラウザー内でprofileを切り替えても、認証済みの不透明なprofile識別子で操作IDを分離し、別profileの操作を照合しません。最初の応答を失った場合も元profileへ戻れば照合できます。
- DSH 0.2.0-rc.2はmanagerが導入元を返さないため、自動更新は手動更新の案内になります。ガラス効果と設定保存は継続できます。
- 切断・自己解除・再起動後は保存した操作IDで照合します。結果不明を成功に変換せず、導入版と実行版が一致するまで更新済みと表示しません。
- 導入直前の記録保存後にも導入元・導入版・ON/OFFを再確認し、他画面が先に導入した新版を下げません。managerの応答だけでなく実際の導入版を確認し、別画面の最新操作を優先して照合します。古い操作の記録を保存しても最新操作の所有権を戻しません。
- 壁紙・透明度・除外・font/themeと、他プラグインのstyleを維持します。更新状態は描画エンジンから独立し、system promptを変更しません。

検証：`npm run check`（unit 141件）、Chromium integration（45件）、実DSH 0.2.0-rc.2／0.2.1-alpha.2の空profileへ配布tgzを導入したnative E2E（各12件）、英語・日本語・中国語の更新UI、390px・reduced-motion・効果OFF・保存拒否・他pluginのfont style、compat、packが成功しました。Windows・macOS実機、実アカウント、公開前の0.2.0タグへの自己更新は未検証です。
